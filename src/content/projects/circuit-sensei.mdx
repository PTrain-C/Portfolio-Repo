## What it is

Learning to breadboard is mostly learning where things go, and a wiring mistake on a first circuit can kill a part before you know what you did. Circuit Sensei sits next to you like a lab TA. You tell it what you want to build and what parts you have. It plans the build as a list of placements with breadboard coordinates like `A10`, draws each step over the live webcam image, checks your work with Gemini Vision before moving on, and once everything is placed it drives an Arduino over USB to actually test the circuit.

## My part

We were a team of 4. I did the hardware integration and circuit testing: I designed and tested the breadboard circuits it walks you through, and the electrical verification path that checks the physical build against the intended schematic. I also wrote the project documentation and the Devpost submission, and prepped for judge Q&A. The software was a team effort, so anything below about how it's built is "we".

## Five states

We built the agent as a small state machine, not a free-form chat, so it can't skip ahead of the hardware. Build steps go through Instruct and Verify; test steps go to the Arduino. Plans can interleave the two.

## The test circuits

The circuits had to be simple enough for someone's first build, and each one had to leave something the Arduino could actually measure. Otherwise "test it for real" would just be the camera again.

| Circuit | How the Arduino checks it |
| --- | --- |
| LED with a current-limiting resistor | Drives the LED from D9 and reads the voltage back on A0 |
| Voltage divider | Reads the midpoint on A0 and compares it to the expected voltage within a tolerance |
| Push button | Reads a digital pin to confirm the button changes state |

The voltage divider in the picture above is the same build: D9, A0, and ground wired into the breadboard at B10, C20, and C30.

## How it's built

| Layer | What it does |
| --- | --- |
| Gemini | Plans the build and does the vision check |
| Python, FastAPI | Hosts the agent loop and state machine; streams messages to the UI over a WebSocket |
| OpenCV | Webcam capture and drawing the overlays |
| Arduino over USB serial | Runs the electrical tests once a build passes |
| React | The workbench UI: live camera, annotated image, step list, chat, and voice |
| ElevenLabs | Reads the agent's replies out loud |
| pytest | Tests for the state machine, the tools, and the Arduino tester |

We also gave it a mock mode that runs end to end with no webcam, no API keys, and no Arduino. The idea is that a classroom can try it before it has any hardware.
