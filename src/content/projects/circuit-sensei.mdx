## What it is

Learning to breadboard is mostly learning where things go, and a wiring mistake on a first circuit can kill a part before you know what you did. Circuit Sensei sits next to you like a lab TA. You tell it what you want to build and what parts you have. It plans the build as a list of placements with breadboard coordinates like `A10`, draws each step over the live webcam image, checks your work with Gemini Vision before moving on, and once everything is placed it drives an Arduino over USB to actually test the circuit.

## Five states

The agent is a small state machine, not a free-form chat, so it can't skip ahead of the hardware. Build steps go through Instruct and Verify; test steps go to the Arduino. Plans can interleave the two.

## How it's built

| Layer | What it does |
| --- | --- |
| Gemini | Plans the build and does the vision check |
| Python, FastAPI | Hosts the agent loop and state machine; streams messages to the UI over a WebSocket |
| OpenCV | Webcam capture and drawing the overlays |
| Arduino over USB serial | Runs the electrical tests once a build passes |
| React | The workbench UI: live camera, annotated image, step list, chat, and voice |
| ElevenLabs | Reads the agent's replies out loud |
| pytest | Tests for the state machine, the tools, and the Arduino tester |

It also has a mock mode that runs end to end with no webcam, no API keys, and no Arduino. The idea is that a classroom can try it before it has any hardware.
