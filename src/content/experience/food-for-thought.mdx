The Food For Thought Foundation is a Los Angeles nonprofit that puts modular hydroponic vertical farms in K-12 schools in underserved communities, where students learn STEM, sustainability, and basic C/C++ through the farms. My part was the controller: the code that reads the water, decides when it needs nutrients or a pH adjustment, and runs the pumps to fix it. I wrote all of it.

It's deadband control with a cap on how much it can dose per cycle, so it can't overdose. EC gets dosed before pH, so adding nutrients doesn't undo the pH correction. The two loops are independent, so if one probe fails the other keeps regulating.

The hardest part was bugs that looked like my own logic and weren't. I spent too long assuming they were. Corrupted sensor reads turned out to be the vendor's sample code parsing the 0xFF bytes an I2C device returns when it has nothing left to say, as if they were data. I also found undocumented limits in the pump protocol that were getting dose commands rejected. What I use from it now: look at what's really on the bus before rewriting code.

The control loop, the code, and the bus story are on the project page.
