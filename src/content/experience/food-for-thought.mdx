The Food for Thought Foundation runs Farms for Thought, and part of that is a hydroponic grow setup. My part was the controller: the code on the Arduino that reads the water, decides when it needs nutrients or a pH adjustment, and runs the pumps to fix it.

I split the firmware into one module per job (pH, EC, temperature, pumps, dosing, lights, WiFi and time) with a single config header, so whoever maintains it next can change a setpoint or a pin without reading the control code.

The most useful thing I did was probably the least visible one: the sensors occasionally returned garbage, and it turned out the read loops weren't stopping on the `0xFF` the I2C bus returns once a device runs out of data. That, the control loop, and the address map are all on the project page.
